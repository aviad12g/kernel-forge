# Fused8 Tasks, Shapes, And Tolerances

The internal fused8 suite is defined in `openkernelforge/tasks/fused_tasks.py`. All paper-facing fused8 tasks use dtype `float32`, deterministic CPU-seeded input generation, and benchmark shape `(4096, 1024)`.

| Task | Operation | Inputs | Output | rtol | atol |
| --- | --- | --- | --- | ---: | ---: |
| `bias_relu` | `relu(x + bias)` with last-dimension bias broadcast | `x: [4096,1024]`, `bias: [1024]` | `[4096,1024]` | 1e-5 | 1e-6 |
| `sigmoid_mul` | `sigmoid(x) * z` | `x: [4096,1024]`, `z: [4096,1024]` | `[4096,1024]` | 1e-5 | 2e-6 |
| `add_relu` | `relu(x + y)` | `x: [4096,1024]`, `y: [4096,1024]` | `[4096,1024]` | 1e-5 | 1e-6 |
| `residual_add_relu` | `relu(x + residual + bias)` with last-dimension bias broadcast | `x: [4096,1024]`, `residual: [4096,1024]`, `bias: [1024]` | `[4096,1024]` | 1e-5 | 1e-6 |
| `bias_gelu` | sigmoid-approximate GELU: `shifted * sigmoid(1.702 * shifted)`, where `shifted = x + bias` | `x: [4096,1024]`, `bias: [1024]` | `[4096,1024]` | 2e-4 | 2e-5 |
| `row_sum` | sum over final dimension | `x: [4096,1024]` | `[4096]` | 1e-4 | 1e-4 |
| `layernorm_small` | layer normalization over final dimension, `eps = 1e-5` | `x: [4096,1024]`, `weight: [1024]`, `bias: [1024]` | `[4096,1024]` | 2e-4 | 2e-4 |
| `rmsnorm_small` | RMS normalization over final dimension, `eps = 1e-5` | `x: [4096,1024]`, `weight: [1024]` | `[4096,1024]` | 2e-4 | 2e-4 |

Verification uses seeds `[0, 1]` and the task benchmark shape unless the config overrides shapes. The final paper-facing fused8 configs use `max_shapes_per_task = 1`.

Input tensors are generated by `torch.randn` using a CPU `torch.Generator` seeded per verification or benchmark case, then moved to the selected device and dtype. Weight-like vectors are generated with smaller scale and offset where appropriate:

- layernorm and rmsnorm weights use scale `0.25` plus `1.0`;
- layernorm bias uses scale `0.1`.
