\paragraph{Historically accepted one-shot candidate: CrossEntropyLoss.}
The historical one-shot Gemini candidate for \code{CE} passed the original policy and correctness checks and was labeled \code{REPEAT\_STABLE\_WIN}. Its recorded speedups are retained in the raw artifact but are provisional because the reference lifecycle was defective. Static inspection shows a row-wise log-sum-exp pattern followed by target-logit gather and a Torch mean reduction. The current \code{ast-v5} policy rejects that high-level reduction when fallback is disabled. The preserved source is under \path{artifacts/runpod_imports/runs/20260520_202314/candidates/.../candidate_000.py}.

{\scriptsize
\begin{verbatim}
@triton.jit
def _cross_entropy_kernel(logits_ptr, targets_ptr, loss_ptr,
                          n_rows, n_cols, BLOCK_SIZE: tl.constexpr):
    row_idx = tl.program_id(0)
    ...
    log_sum_exp = max_val + tl.log(sum_exp)
    target = tl.load(targets_ptr + row_idx)
    target_logit = tl.load(logits_ptr + row_idx * n_cols + target)
    tl.store(loss_ptr + row_idx, log_sum_exp - target_logit)

def forward(predictions, targets):
    n_rows, n_cols = predictions.shape
    loss = torch.empty(n_rows, device=predictions.device,
                       dtype=predictions.dtype)
    _cross_entropy_kernel[(n_rows,)](...)
    return loss.mean()
\end{verbatim}
}

\paragraph{Failed one-shot candidate: 4D tensor matmul.}
The historical \code{matmul\_4d} candidate passed static policy but failed verification before timing with a Triton compilation error. It attempts a blocked matmul over a flattened 4D tensor, but pointer and mask ranks do not match. The verifier records \code{triton.compiler.errors.CompilationError} with summary \code{Cannot broadcast, rank mismatch: ['1','1','32'], ['16','1','1','32']}. The failure was labeled high repairability because it is localized to pointer arithmetic and mask shape; the single repair attempt did not verify.

{\scriptsize
\begin{verbatim}
A_ptr_base = A_ptr + (rm[:, None, None, None] // (256 * 512)) * stride_ab + ...
acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)
for k in range(0, K, BLOCK_K):
    a = tl.load(
        A_ptr_base + (rk[None, None, :] + k) * stride_al,
        mask=rk[None, None, :] + k < K,
        other=0.0,
    )
    b = tl.load(B_ptr + (rk[:, None] + k) * stride_bk + rn[None, :], ...)
    acc += tl.dot(a.reshape(BLOCK_M, BLOCK_K), b)
\end{verbatim}
}
